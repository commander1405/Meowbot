# MEGA BOT — نسخه روبیکا

نسخهٔ **مستقل** از MEGA BOT برای پیام‌رسان **روبیکا**.  
روی MeowBot بله هیچ تغییری اعمال نشده و اجرای این ربات، MeowBot را متوقف یا خراب نمی‌کند.

## ساختار

```
MeowBot/                    # همان فایل‌های قبلی MeowBot بله
├── mega_rubika/            # پکیج مستقل روبیکا
│   ├── config.py
│   ├── api.py              # کلاینت Bot API روبیکا
│   ├── database.py         # SQLite
│   ├── bot.py              # منطق و منوها
│   ├── keyboards.py
│   ├── main.py             # نقطه ورود
│   ├── content/            # جوک، حافظ و ...
│   └── .env.example
├── data/
│   └── mega_rubika.db      # ساخته می‌شود خودکار
├── run_mega_rubika.py
└── requirements.txt
```

## نصب

```bash
pip install -r requirements.txt
```

وابستگی‌های اضافه فقط برای روبیکا: `aiohttp`, `aiosqlite`, `python-dotenv`.

## تنظیمات

یکی از این دو روش:

1. فایل `mega_rubika/config.py` را باز کن و:
   - `BOT_TOKEN` / از env: `RUBIKA_BOT_TOKEN`
   - `OWNER_ID` / از env: `RUBIKA_OWNER_ID` (شناسه کاربر روبیکا، معمولاً با `u0` شروع می‌شود)

2. یا `.env` بساز (از روی `.env.example`):

```env
RUBIKA_BOT_TOKEN=توکن_ربات_روبیکا
RUBIKA_OWNER_ID=u0xxxxxxxx
```

اگر این دو مقدار خالی باشند، برنامه با پیام واضح متوقف می‌شود و اجرا نمی‌شود.

## اجرا

```bash
# از ریشه ریپو
python run_mega_rubika.py

# یا
python -m mega_rubika.main
```

MeowBot بله را جداگانه مثل قبل اجرا کن (`python main.py`). دو ربات می‌توانند همزمان روی یک سرور باشند چون توکن، دیتابیس و نقطه ورود کاملاً جدا هستند.

## قابلیت‌های پیاده‌شده (واقعی)

| قابلیت | وضعیت |
|--------|--------|
| منوی اصلی + کیبورد روبیکا | ✅ |
| /start /help /stats | ✅ |
| درباره، پشتیبانی، حمایت مالی | ✅ |
| جوک و فال حافظ | ✅ |
| پنل مالک (/owner) با تشخیص OWNER_ID | ✅ |
| آمار کاربران و گروه‌ها | ✅ |
| ثبت کاربر/گروه در SQLite | ✅ |
| بن داخلی با پرونده و کد | ✅ (API آماده، دستورات در حال گسترش) |
| مدیریت خطا و لاگ بدون افشای توکن | ✅ |
| دیتابیس پایدار در `data/mega_rubika.db` | ✅ |

## محدودیت‌های واقعی API روبیکا

- **بن/اخراج واقعی عضو گروه**: متدهای `banChatMember` در کلاینت هست، ولی سطح دسترسی ربات در گروه و پشتیبانی واقعی سرور روبیکا را باید با توکن خودت تست کنی. بن **داخلی** (مسدود کردن استفاده از قابلیت‌های ربات) همیشه کار می‌کند و به API وابسته نیست.
- **Webhook**: فعلاً long-polling (مثل اکثر کتابخانه‌های روبیکا).
- **پیام همگانی**: اسکلت آماده است؛ قبل از استفادهٔ سنگین باید rate-limit پلتفرم رعایت شود.
- ساختار آپدیت/دکمه روبیکا با بله یکی نیست؛ برای همین کلاینت جدا نوشته شده، نه کپی از `bale_api`.

## تست‌هایی که با توکن واقعی باید بزنی

1. `python run_mega_rubika.py` بدون کرش
2. `/start` و ظاهر شدن منو
3. دکمه‌های منو (جوک، آمار، درباره)
4. `/owner` فقط با شناسه مالک
5. خاموش/روشن کردن و ماندن داده در SQLite
6. اینکه `python main.py` (MeowBot) هنوز مثل قبل کار کند

بدون توکن روبیکا نمی‌توانم اتصال واقعی را اینجا تست کنم؛ ساختار و کد آماده است.

## امنیت

- توکن و OWNER_ID را در گیت کامیت نکن.
- `.env` و `*.db` در `.gitignore` هستند.
- لاگ‌ها توکن را redact می‌کنند.

## ادامه توسعه

برای اضافه کردن دستورات مدیریتی بیشتر (بن با ریپلای، پیام همگانی کنترل‌شده، ویرایش متن درباره، و ...):

- منطق را در `bot.py` گسترش بده
- جداول لازم از قبل در `database.py` هست (`moderation_cases`, `audit_logs`, `team_members`, ...)
